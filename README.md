# Files — 定制版

基于 [Files](https://github.com/files-community/Files) 的定制分支，在原版功能之上增加了多项效率特性。

## 新增功能

### 多窗格布局（双窗格 / 四窗格 Grid）

- 工具栏或标签右键菜单中即可将当前标签拆分为多窗格：左右、上下或 **2×2 四窗格 Grid**。
- 每个窗格独立导航、独立排序，窗格分隔条可拖动调整比例。

### 每窗格独立文件夹标签

- 多窗格模式下，每个窗格顶部都有自己的标签条。
- 点击标签切换窗格所在目录；中键或 × 关闭；"+" 将当前文件夹复制为新标签。
- 单窗格开启多个标签时标签条同样出现，可与全局标签配合使用。
- 窗格标签随会话持久化，重启后自动恢复。

### Windows 原生右键菜单

- 设置 → 常规 → **使用 Windows 原生右键菜单**。
- 开启后右键直接弹出 Win32 原生菜单，完整支持第三方 Shell 扩展（杀毒扫描、Git、压缩包工具等）。
- 任何时候按住 **Shift** 右键，可临时切换到另一种菜单（与资源管理器"显示更多选项"习惯一致）。

### 布局配置（Workspace Profiles）

- 标签栏 "+" 菜单 → **布局配置** → 保存当前布局：一键记录当前标签的窗格排列（水平/垂直/Grid）、各窗格路径与配色方案。
- 已保存的布局显示在同一子菜单中，点击即在**新标签页**完整还原整套工作区。
- 数据保存在 `settings\layout_profiles.json`（设置目录下），可直接编辑批量管理；菜单中"编辑配置文件"用系统默认编辑器打开。

文件格式示例：

```json
[
  {
    "Name": "工作区",
    "Arrangement": "Grid",
    "PanePaths": ["D:\\proj", "D:\\docs", "C:\\Users", "E:\\logs"],
    "ColorSchemeHex": "#6600E5FF",
    "ApplyColorScheme": true
  }
]
```

### 顶层标签重命名

- 右键任意标签 → **重命名**，可为工作目录设置备注名（如"项目源码"、"文档"）。
- 重命名后标题固定显示自定义名，导航变化不再覆盖；路径仍保留在悬停提示中。
- 自定义名随会话持久化，重启后自动恢复；再次重命名并清空输入即还原自动标题。

### 应用信息

- 应用名：**FilesPlus**（主程序 `FilesPlus.exe`，免安装绿色版，解压后直接运行）
- 基于开源文件管理器 [Files](https://github.com/files-community/Files) 定制

### 自定义工具按钮

- 工具栏 "+" 菜单 → **添加自定义工具**：填写名称、可执行文件路径与启动参数，即可把常用程序固定到工具栏。
- 每个工具显示为独立按钮，并自动展示该程序的图标；点击直接启动。
- 右键工具按钮可将其移除；增删即时生效，配置随设置持久化。

### 科技感配色

设置 → 外观 → 背景颜色，新增三个荧光配色：

| 配色 | 效果 |
|---|---|
| 赛博霓虹（Cyber neon） | 青色荧光 |
| 赛博紫罗兰（Cyber violet） | 紫色荧光 |
| 赛博薄荷（Cyber mint） | 薄荷绿荧光 |

配合深色主题使用效果最佳。

### 内容全文搜索（content: 查询）

- 搜索框支持 `content:关键词` 语法（可用 `c:` 简写，全角冒号 `c：` 同样识别，适配中文输入法），全文检索文件**内容**而不只是文件名。
- 优先走 Windows Search 索引，秒级返回；索引未覆盖的位置自动回退到逐文件读取匹配。
- 支持 Office 文档正文检索：直接解析 `.docx` `.docm` `.pptx` `.pptm` `.xlsx` `.xlsm` 内部 XML，无需安装 Office。
- 单文件扫描大小上限可在 设置 → 文件夹 中调整，避免超大文件拖慢全盘搜索。
- 文件内容读取采用流式匹配，找到即停，无 BOM 的 UTF-8 文件同样正确匹配。

### 搜索体验优化

- 搜索期间列表中央显示**进度环 + "正在搜索…"**，不再闪现误导性的"无结果"。
- 结果就绪后提示自动消失；确认无匹配时才显示"没有与搜索条件匹配的项"。
- 结果随扫描增量出现（阈值批量刷新），无需等全盘扫完。

## 构建

```powershell
.\run-unpackaged.ps1    # 构建 + 启动（免打包版）
```

要求：Windows 10 1809+ / Windows 11、.NET SDK、Visual Studio 2022（含 UWP/WinUI 工作负载）。
